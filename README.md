# Logistic-Regression

# Tekworks - Logistic Regression Project

## Overview
This project contains implementations and analysis of logistic regression models applied to HR analytics data.

## Project Structure

- **app.py** - Main application script
- **IBM HR Analytics.csv** - Dataset containing HR analytics information
- **logisticregression_prac.ipynb** - Practice notebook for logistic regression experiments
- **Logistic regression/** - Folder containing detailed logistic regression implementation
  - **logisticregression.ipynb** - Complete logistic regression notebook

## Getting Started

### Requirements
- Python 3.x
- pandas
- scikit-learn
- jupyter (for running notebooks)

### Installation
1. Clone or download this repository
2. Install required packages:
   ```bash
   pip install pandas scikit-learn jupyter numpy matplotlib
   ```

## Usage

### Running the Application
```bash
python app.py
```

### Running Notebooks
```bash
jupyter notebook logisticregression_prac.ipynb
```
or
```bash
jupyter notebook Logistic\ regression/logisticregression.ipynb
```

## Dataset
The project uses the IBM HR Analytics dataset which contains employee information and various HR metrics.
